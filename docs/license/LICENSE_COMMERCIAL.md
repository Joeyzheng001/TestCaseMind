## 使用条款

### 1. 获得许可证

被许可人可以通过以下方式之一获得有效的License Code：

- **购买商业许可证** - 适用于商业用途
- **购买个人许可证** - 适用于个人学术用途
- **试用许可证** - 30天免费试用（无需购买）

### 2. 许可证激活

获得License Code后，被许可人必须通过以下命令激活许可证：

```bash
python -m src.license_cli activate "YOUR_LICENSE_CODE"
```

许可证将被保存到本地，在License有效期内无需重复激活。

### 3. 许可证验证

被许可人可以随时验证许可证状态：

```bash
python -m src.license_cli status
```

## 条款和条件

### 1. 许可证有效期

许可证从激活之日起生效，在购买时指定的天数后自动过期。被许可人可以通过续费来延长许可证有效期。

### 2. 自动续费

某些许可证（如年度许可证）可能设置自动续费。被许可人可以在任何时间取消自动续费。

### 3. 许可证转移

许可证绑定到首次激活的机器。如需转移到其他机器，请联系support@thesismind.com。

**企业许可证**: 可以转移到最多5台机器。

### 4. 多用户使用

- **个人许可证**: 仅限单个用户使用
- **商业许可证**: 最多5个用户
- **企业许可证**: 无限用户数

共享License Code属于违反许可协议，将导致许可证撤销。

### 5. 数据和隐私

被许可人的使用数据可能被收集用于改进服务。所有数据将根据我们的隐私政策进行保护。

### 6. 免责声明

软件"按现状"提供。许可方不对任何间接、附带、特殊或后果性损害负责，即使已被告知其可能性。

### 7. 支持和维护

- **试用/个人**: 社区支持，邮件支持
- **商业**: 优先邮件支持，7天内响应
- **企业**: 24/7电话和邮件支持，2小时SLA

### 8. 更新和升级

许可证包括所有主要版本更新。被许可人无需额外付费即可使用最新版本。

### 9. 退款政策

- **7天无理由退款** - 购买后7天内
- **30天满意度保证** - 30天内对服务不满意可申请退款
- 许可证已激活后不可退款

### 10. 许可证管理

被许可人可以通过以下命令管理其许可证：

```bash
# 查看许可证状态
python -m src.license_cli status

# 验证许可证代码
python -m src.license_cli verify "LICENSE_CODE"

# 删除本地许可证
python -m src.license_cli remove

# 创建试用许可证
python -m src.license_cli trial
```
