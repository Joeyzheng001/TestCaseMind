# 引用文献管理技能库

## 引用文献的重要性

### 为什么要引用文献?
1. **学术诚实** - 尊重他人的研究成果
2. **支撑论点** - 用数据和权威来论证
3. **建立联系** - 将自己的工作与现有研究联系起来
4. **便于追溯** - 读者可以追查来源

### 引用的原则
- **准确性** - 引用信息必须完整准确
- **一致性** - 全文采用同一引用格式
- **适度性** - 引用要恰到好处，不过度
- **透明性** - 清楚标注引用来源

## 常见引用格式

### 1. APA格式 (美国心理学会)

**书籍**:
```
Smith, J., & Johnson, K. (2020). Title of the book. Publisher.
```

**期刊文章**:
```
Smith, J., Johnson, K., & Williams, L. (2020). Title of the article. 
Journal Name, 45(3), 123-145.
```

**网络资源**:
```
Smith, J. (2020). Title of article. Retrieved from 
https://www.example.com/article
```

**文中引用**:
```
(Smith & Johnson, 2020)
```

### 2. GB/T 7714-2015 格式 (中文学位论文标准)

**书籍**:
```
[序号] 作者. 书名[M]. 出版地: 出版社, 出版年.
例: [1] 张三, 李四. 人工智能原理[M]. 北京: 清华大学出版社, 2020.
```

**期刊文章**:
```
[序号] 作者. 文章题名[J]. 期刊名, 年份, 卷号(期号): 页码.
例: [2] 王五. 深度学习在医学影像中的应用[J]. 计算机学报, 2020, 43(5): 1001-1015.
```

**会议论文**:
```
[序号] 作者. 论文题名[C]//会议名. 出版地: 出版社, 出版年: 页码.
例: [3] 赵六. 神经网络优化方法[C]//第五届人工智能学术会议. 北京: 中国计算机学会, 2020: 45-52.
```

**网络资源**:
```
[序号] 作者. 资源题名[EB/OL]. 发布地: 发布机构, 发布日期[引用日期]. URL.
例: [4] 刘七. AI技术综述[EB/OL]. 北京: 知识库, 2021-01-01[2021-06-15]. http://example.com
```

**学位论文**:
```
[序号] 作者. 论文题名[D]. 学位授予单位, 学位授予年份.
例: [5] 孙八. 图神经网络在推荐系统中的应用[D]. 清华大学, 2021.
```

### 3. Chicago格式 (历史和人文学科)

**脚注**:
```
John Smith, "Article Title," Journal Name 45, no. 3 (2020): 123.
```

**参考文献表**:
```
Smith, John. "Article Title." Journal Name 45, no. 3 (2020): 123-145.
```

### 4. Harvard格式 (英国风格)

**文中引用**:
```
Smith (2020) argues that...
Recent studies (Smith, 2020) show that...
```

**参考文献表**:
```
Smith, J., 2020. Title of article. Journal Name, 45(3), pp.123-145.
```

## 文献管理工具

### 1. Zotero (开源免费)
**优点**:
- 完全开源，永久免费
- 支持浏览器插件自动保存
- 自动生成多种格式引用
- 支持笔记和标签

**缺点**:
- 云存储有空间限制（300MB免费）

### 2. Mendeley
**优点**:
- 功能完整
- PDF阅读和标注
- 云端同步

**缺点**:
- 某些功能收费
- 存储空间有限

### 3. EndNote
**优点**:
- 功能最完整
- 在线版本可用

**缺点**:
- 软件收费（较贵）
- 学习曲线陡

### 4. BibTeX
**优点**:
- 与LaTeX无缝整合
- 格式标准化
- 易于版本控制

**缺点**:
- 需要手动编辑
- 没有可视界面

## 文献检索策略

### 第1步: 确定关键词
```
主要关键词 (Primary keywords):
- 深度学习, Deep Learning

扩展关键词 (Extended keywords):
- 神经网络, 卷积神经网络, CNN
- Neural Network, Convolutional Neural Network

同义词 (Synonyms):
- 机器学习, Machine Learning
- 人工智能, Artificial Intelligence
```

### 第2步: 构造检索式
```
AND: 并集 - 所有关键词都要包含
  例: (深度学习 OR 神经网络) AND 医学影像

OR: 或集 - 至少包含一个关键词
  例: 卷积神经网络 OR CNN OR ConvNet

NOT: 非集 - 排除某些内容
  例: 深度学习 NOT 游戏 (排除游戏相关)

NEAR/N: 邻近 - 关键词在N个单词内
  例: 深度学习 NEAR/5 诊断
```

### 第3步: 筛选结果
1. **按发布时间** - 通常选择最近3-5年
2. **按期刊等级** - 优先选择高影响因子期刊
3. **按被引量** - 高被引论文质量较好
4. **阅读摘要** - 快速判断相关性

## 引用的最佳实践

### 什么时候需要引用?

✓ **需要引用**:
- 引用他人的原始观点
- 使用他人的数据、统计结果
- 引用他人的方法、模型
- 对他人工作的总结或改进

✗ **不需要引用**:
- 众所周知的事实（如"地球是圆的"）
- 常识性知识
- 自己的原创分析
- 一般性陈述

### 引用的规范方式

**直接引用** (少用，仅在关键时):
```
根据Smith(2020)的研究：
"这个现象的发生机制是..." [5]
```

**间接引用** (主要方式):
```
Smith(2020)发现该机制可以解释此现象。
```

**综合引用**:
```
多项研究表明这一结论(Smith 2020; Johnson 2021)。
```

### 避免的问题

❌ **过度引用**:
- 每句话都引用，显得论文没有自己的想法

❌ **引用不当**:
- 引用过时的论文而忽视最新研究
- 引用二手来源而不是原始论文

❌ **格式不一**:
- 同一篇论文中引用格式不统一

❌ **遗漏引用**:
- 改述他人观点却没有引用（构成抄袭）
