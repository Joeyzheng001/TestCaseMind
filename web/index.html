写论文，最怕的不是写不出来
而是写出来的前后矛盾、引用造假

ThesisMind 不是在跟你聊天。它在你的论文背后运行一套承诺-验证引擎，确保第一章做出的每一个承诺，在第六章之前都被兑现。

🔄

承诺-验证闭环

每写完一节，系统从正文中自动提取数量、方法、数据、定义四类承诺。写下游章节时，未兑现的承诺会变成硬约束注入 prompt，写完后再反向校验。前文说过的，后文必须兑现。

📦

动态方法注册表

所有方法名、别名、阶段归属、领域适配从 cards.sqlite3 数据库动态加载，杜绝硬编码。"AHP" 和 "层次分析法" 被映射为同一方法，在所有章节中保持一致。

✅

引用双重验证

入库前：LLM 验证作者+标题+期刊是否为真实文献，虚构的直接丢弃。生成后：程序检测正文中的 [N] 标记，发现超过引用池大小的编号立即告警 — 这是 LLM 编造引用的典型特征。

📚

知识库锚定生成

大纲不凭空创造 — 从向量库检索相似论文的真实结构。章节内容注入方法卡片的完整操作步骤和约束。你的文献资料不会在上下文窗口滚出后"消失"。

🧠

累积式论文记忆

thesis_memory 随写作流程持续增长：问题列表、方案设计、指标体系、术语定义、章节摘要。不是 LLM 的上下文窗口 — 是持久化的结构化记忆，越写越了解你的论文。

🔍

跨章节全量编译检查

全部写完后，系统把所有草稿拼接起来逐章验证。不是"让 LLM 帮你检查一下" — 是程序化的规则匹配，没通过就是没通过。
