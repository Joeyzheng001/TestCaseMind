Python 安装配置指南

ThesisMind 需要 Python 3.9 或更新版本。请按以下步骤操作。

1 下载 Python 安装包

打开浏览器访问： https://www.python.org/downloads/

点击黄色按钮下载最新版（当前为 3.12 或 3.13）。推荐 64 位版本（python-3.x.x-amd64.exe）。

注意：不要下载 Python 3.7 或更低版本。ThesisMind 最低要求 3.9。

2 运行安装程序（关键步骤）

双击下载的 .exe 文件，务必勾选底部两个选项：

  • ✅ Add python.exe to PATH（将 Python 加入系统路径）
  • 如果看到 "Use admin privileges" 也勾上

然后点击 "Install Now"，等待安装完成。安装成功后关闭窗口。

为什么必须勾选 Add to PATH？
不勾选的话，命令行中无法识别 python 命令，ThesisMind 安装脚本将无法运行。

3 验证安装

按 Win + R，输入 cmd，回车打开命令提示符。输入：

C:\Users\你的用户名> python --version

应输出类似：

Python 3.12.3

如果显示 'python' 不是内部或外部命令，说明未勾选 PATH，需要重新安装或手动添加环境变量。

4 回到 ThesisMind

Python 安装成功后，双击 ThesisMind 目录下的 setup.bat 即可完成一键安装。

C:\Users\你的用户名> cd ThesisMind-v20250520
C:\...\ThesisMind-v20250520> setup.bat

常见问题

Q: 公司电脑有安全策略，无法安装软件？
联系 IT 部门申请安装 Python 3.9+，或使用公司内部软件中心（如 Software Center）搜索 "Python"。

Q: Microsoft Store 里的 Python 能用吗？
能，搜索 "Python 3.12" 安装即可。但 Store 版本的路径有时会出问题，推荐优先用官网安装包。

Q: 已经装了 Python 3.7 怎么办？
需要升级到 3.9+。建议卸载 3.7 后安装新版，或保留 3.7 同时安装新版（需注意 PATH 顺序）。

1 检查系统自带的 Python

打开终端（在"启动台 → 其他 → 终端"或按 Cmd + Space 搜索 "Terminal"），输入：

$ python3 --version

macOS 通常预装了 Python 3.9+。如果输出类似 Python 3.9.x 或更高，即可直接使用，跳到第 3 步。

2 安装 Python（二选一）

方案 A — Homebrew 安装（推荐）：

如果已安装 Homebrew，终端中运行：

$ brew install python@3.12

方案 B — 官网安装包：

访问 python.org/downloads， 下载 macOS 安装包（.pkg 文件），双击运行，一路 "继续" 即可。

3 验证安装

$ python3 --version

应输出：

Python 3.12.3

同时确认 pip 可用：

$ pip3 --version

4 启动 ThesisMind

回到 ThesisMind 解压目录，在终端中运行安装脚本：

$ cd ~/Downloads/ThesisMind-v20250520
$ bash setup.sh

安装完成后启动：

$ source .venv/bin/activate
$ python3 src/web_server.py --port 8222

浏览器访问 http://localhost:8222。

常见问题

Q: 提示 "command not found: brew"？
Homebrew 未安装。先去 brew.sh 安装，或用方案 B 官网安装包。

Q: 系统自带的是 Python 2.7？
很旧的 macOS 版本才会这样。输入 python3 而非 python，或升级 macOS。

Q: Apple Silicon (M1/M2/M3) 需要注意什么？
不需要特殊处理。Python 3.9+ 原生支持 Apple Silicon，官网安装包会自动识别芯片架构。
