# 引用适配度技能库

## 适配度维度

评估引用文献与特定章节/小节的匹配程度。

### 1. 主题相关性 Topic (40%)
BGE 嵌入向量余弦相似度对比：
- 引用端：标题 + 摘要 + 关键词
- 章节端：小节草稿文本 + 小节标题
- 相似度 > 0.7 视为高度相关
- 降级方案：关键词 Jaccard 重叠

### 2. 方法匹配 Method (25%)
引用标注的研究方法与章节选用方法的重叠度：
- 引用 methods_json ↔ 章节选用方法列表
- 完全匹配 > 部分匹配 > 无交集

### 3. 关键词覆盖 Keyword (20%)
引用关键词与章节关键词的匹配度：
- 中文 2-gram 词块提取
- 英文 3+ 字母单词匹配
- 覆盖率 × 2.5 缩放

### 4. 时效适配 Recency (15%)
文献年份与章节类型的适配：
- 绪论章 (Ch1)：接受经典文献，年份宽容度高
- 文献综述/理论基础 (Ch2)：平衡
- 研究方法 (Ch3)：偏好近期文献（≤5年）
- 实证分析 (Ch4)：偏好近期文献
- 结论 (Ch6)：接受较宽泛年份范围

## 适配度等级

| 分数 | 星级 | 含义 |
|-----|------|------|
| 85-100 | ★★★ | 高度适配 |
| 65-84 | ★★☆ | 适配 |
| 45-64 | ★☆☆ | 部分适配 |
| <45 | ☆☆☆ | 低适配 |

## 使用方式

```
POST /api/citation-cards/relevance
GET /api/citation-cards/relevance-quick?card_id=...&draft_key=...
```

- 批量接口：提交 card_ids + draft_key（或直接传 section_text）
- 快速接口：单条查询，在引用选择时实时展示

## 前端展示

引用库表格增加「适配度」列：
- ★★★ 绿色：高度适配，建议优先选用
- ★★☆ 蓝色：基本适配，可选用
- ★☆☆ 橙色：部分适配，需人工判断
- ☆☆☆ 灰色：低适配，不建议选用

## 参考开源项目

- SPECTER (Allen AI) — 学术文档嵌入，论文匹配
- Aspire (Allen AI) — 共引监督的多向量模型，细粒度相似性
- SECTOR — 多维文本匹配，语义对齐
- semantic-scholar-skills — 引用上下文追踪与意图标注
- markrel — 马尔可夫链文档相关性，嵌入无关
